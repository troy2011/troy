# SPIN TAROT Pachislot Redesign Spec

## 1. 目的

本仕様書は、現行の `Spin Tarot` を「スロット風の見た目を持つカードゲーム」から、「パチスロ的な期待感と中毒性を持つスロットゲーム」へ再設計するための基準を定義する。

目的は次の3点。

- 1ゲームごとに期待が積み上がる通常時を作る
- 上位状態への突入期待と継続期待を明確にする
- 演出強化の前に、ゲームループ自体を中毒性のある構造へ作り直す

本仕様は実装順の基準でもあり、まず現行 DOM UI で面白さを成立させ、その後に Phaser による演出強化を行う。

## 2. 現行版の課題

### 2.1 期待の波が弱い

- 通常ゾーンが長すぎる
  - `天国 30G / 通常 80-120G / 天井 250G`
- 防衛戦までの山場が遠く、通常時の刺激が薄い
- 外れ時の進行価値が弱く、レバーオンの意味が薄い

### 2.2 内部成長が見えない

現行 engine は以下の内部値を持つ。

- 人口
- 騎士
- ビショップ
- 魔法使い
- 国家ランク
- `queenGauge`
- `kingGauge`

しかし UI 上はほぼ見えず、育成実感が出ない。

### 2.3 死に変数が存在する

- `queenGauge`
- `kingGauge`

これらは増加するが、現在は具体的な到達演出や放出先を持たない。

### 2.4 大アルカナと小アルカナの選択性が弱い

- 大アルカナは5Gごとに自動差し替えで、狙う感覚が弱い
- 小アルカナの HOLD 判断は一部ランクを除き平板

### 2.5 継続欲求と保存性が噛み合っていない

- 現行は state 非永続
- タブ離脱で run が消える
- 「あと少しで当たりそう」が次回へ残らない

## 3. 再設計の方針

### 3.1 目標体験

目指す体験は次の流れ。

1. 通常時でも常に何かが進む
2. 前兆や高確の気配が頻繁に出る
3. 外れでも完全な無ではない
4. 上位状態に入る理由が見える
5. 当たった後は「伸ばす時間」がある
6. 1スピンごとの演出が短く気持ちいい

### 3.2 再設計の原則

- ハズレにも価値を持たせる
- 数値の成長を必ず可視化する
- 状態を段階化する
- 上位状態の入口を複数用意する
- 大当たり後は即終了させず上位ゾーンへ繋ぐ
- 演出はロジックのあとに載せる

## 4. ゲーム全体像

### 4.1 コアループ

新しいスピンタロットは以下のループで回る。

1. 通常時を回す
2. 外れや小役で各ゲージを貯める
3. 前兆、高確、チャンスゾーンへ入る
4. 防衛戦またはボーナスへ当選する
5. 報酬で戦力、ランク、上位状態を伸ばす
6. 通常時へ戻る、または上位状態を継続する

### 4.2 ゲームの見え方

プレイヤーには「城を育てながら、敵襲やアルカナ加護を抽選するパチスロ」として見せる。

テーマは以下。

- 通常時: 遠征、予兆、占い、蓄積
- CZ: 侵攻準備、防衛布陣、神託一致
- ボーナス: 防衛戦、宝島、ロングフリーズ
- 上位AT: 神託連戦、世界制圧モード

## 5. 状態機械

### 5.1 基本状態

- `normal`
  - 通常時
- `hint`
  - 前兆
- `high`
  - 高確
- `cz`
  - チャンスゾーン
- `battle`
  - 防衛戦ボーナス
- `bonus`
  - 宝島などの報酬ゾーン
- `at`
  - 上位継続ゾーン
- `freeze`
  - ロングフリーズ
- `gameover`
  - 城壁崩壊

### 5.2 遷移イメージ

- `normal -> hint`
  - 予兆ゲージ到達
  - 特定小役連続
  - レアアルカナ示唆
- `hint -> high`
  - 演出成功
  - 内部モード昇格
- `high -> cz`
  - 規定ゲーム
  - 役成立
  - 神託一致
- `cz -> battle`
  - 成功
- `cz -> normal`
  - 失敗
- `battle -> bonus`
  - 勝利時の一部
- `battle -> at`
  - 勝利かつ条件達成
- `battle -> normal`
  - 通常勝利後
- `bonus -> high`
  - 消化後の引き戻し
- `bonus -> at`
  - 上位昇格
- `at -> at`
  - 継続
- `at -> high`
  - 転落後の高確
- `any -> freeze`
  - ロングフリーズ契機

## 6. 通常時の再設計

### 6.1 ゲーム数の短縮

現行のゾーン長は長すぎる。再設計では以下を基準値とする。

- 天国: `6-8G`
- 通常: `12-18G`
- 深追い: `24-36G`

重要なのは、常に「あと少しで何かが起きそう」にすること。

### 6.2 ハズレの価値

ハズレでも最低1つは進行する。

- 予兆ゲージ加算
- `queenGauge` 加算
- `kingGauge` 加算
- 次ゲーム高確率示唆
- オーメン一致率アップ
- CZ 天井短縮

ハズレが完全な無になるのは避ける。

### 6.3 小役相当の定義

パチスロ感を出すため、役を再分類する。

- リプレイ相当
  - ワンペア
- ベル相当
  - ツーペア
- 弱レア役
  - スリーカード / ストレート
- 強レア役
  - フラッシュ / フルハウス
- ボーナス級
  - フォーカード以上

現行の `OnePair = 配当0` は維持しない。  
ワンペアは「出玉は弱いが、状態進行には意味がある」役へ変更する。

### 6.4 神託一致システム

現行の `previewSuit` と `omenBreak` を発展させる。

- 毎ゲーム、神託スートを提示
- 一致したライン役で前兆ゲージ大加算
- 不一致勝利は `法則崩れ` として高期待演出
- 神託一致が続くほど CZ 期待度アップ

## 7. ゲージ再設計

### 7.1 可視化するゲージ

UI で常時表示する。

- 城壁 HP
- 国家ランク
- 予兆ゲージ
- `queenGauge`
- `kingGauge`
- 騎士 / ビショップ / 魔法使い

### 7.2 queenGauge の役割

`queenGauge` は支援系の上位状態に使う。

- 満タンで `星告の加護` 発動
- 一定G、以下の恩恵
  - 回復しやすい
  - カップ / ワンド優遇
  - 宝島当選率アップ
  - ボーナス後引き戻し優遇

### 7.3 kingGauge の役割

`kingGauge` は攻撃系の上位状態に使う。

- 満タンで `王権ラッシュ` 発動
- 一定G、以下の恩恵
  - 攻撃倍率アップ
  - ソード / ペンタクル優遇
  - 防衛戦突入率アップ
  - バトル勝利時の AT 昇格率アップ

### 7.4 rankGauge の役割

国家ランク上昇は恒久成長とする。

- 城壁上限上昇
- 敵襲勝利報酬上昇
- 上位アルカナ pool 解放
- 演出ランク上昇

## 8. 大アルカナ再設計

### 8.1 配布方法

現行の「5Gごとランダム差し替え」は廃止する。

新仕様:

- 通常時は `候補2枚提示 + 片方を点灯`
- プレイヤーは抽選結果を見るだけでもよい
- 将来的には「条件達成で片方を選ぶ」へ拡張可能

### 8.2 配置ルール

- 通常時アルカナ
  - 低〜中期待
- 前兆 / 高確アルカナ
  - CZ に寄る
- 防衛戦アルカナ
  - 火力、回復、突破補助
- フリーズ専用アルカナ
  - 愚者、世界

### 8.3 アルカナの設計原則

各大アルカナは、少なくとも次のどれかに明確に寄せる。

- 通常時強化
- CZ 突入補助
- バトル突破補助
- 出玉増加
- 上位AT移行

「効果はあるが体感しにくい」ものは削る。

## 9. 小アルカナと HOLD の再設計

### 9.1 現行の問題

現行では HOLD の意味が一部ランクに偏っている。

### 9.2 目標

各ランク、またはランク帯に「保持理由」を持たせる。

### 9.3 ランク帯の役割

- `A`
  - 王者系ゲージ加算
  - 上位状態の鍵
- `2-4`
  - 通常時補助
  - 救済、前兆、再抽選
- `5-7`
  - CZ 用
  - 滑り、保証、スート寄せ
- `8-10`
  - 攻撃倍率、破壊、継続補助
- `J/Q/K`
  - 戦力成長
  - 騎士 / ビショップ / 魔法使い / ゲージ上昇

### 9.4 HOLD 判断の体感

HOLD は「役を作るため」だけでなく、以下の判断になるべき。

- 今回当てに行くか
- 次の CZ へ寄せるか
- ゲージを育てるか
- 上位状態の鍵を狙うか

## 10. CZ 設計

### 10.1 CZ の役割

通常時とボーナスの間に「期待を煽る層」を置く。

### 10.2 CZ 案

#### 侵攻準備

- 5G固定
- 神託一致で成功率アップ
- 最終ゲームで敵襲抽選

#### 結界防衛

- ワンペア以上で防衛力加算
- 累積値で突破

#### 女王の審議

- `queenGauge` 契機
- 成功で宝島 or 回復ボーナス

#### 王の進軍

- `kingGauge` 契機
- 成功で防衛戦 or AT

### 10.3 CZ 成功率

初期案:

- 通常 CZ: `30-40%`
- 強 CZ: `45-60%`
- 上位前提 CZ: `60%+`

## 11. 防衛戦ボーナス再設計

### 11.1 役割

防衛戦はメインボーナス。  
単なる敵HP 削りではなく、「突破すると報酬が連鎖するボーナス」とする。

### 11.2 防衛戦の構造

- 1戦 `3-6G`
- 毎Gで役に応じて攻撃
- 敵ごとに個性あり
- 勝利で以下を抽選
  - コイン
  - 強アルカナ
  - 宝島
  - 上位AT

### 11.3 敵国の役割整理

- ソード国
  - 高攻撃、短期決戦
- カップ国
  - 回復型、継続戦
- ワンド国
  - HOLD 妨害、前兆崩し
- ペンタクル国
  - 高耐久、突破報酬が大きい

### 11.4 勝利報酬

勝利報酬は「単発 coin」で終わらせず、次を用意する。

- 通常勝利
  - coin
  - 高確移行
- 強敵勝利
  - coin
  - 強アルカナ
  - AT 抽選
- ボス勝利
  - coin
  - AT 確定 or フリーズ高期待

## 12. 上位状態設計

### 12.1 宝島ボーナス

現行の treasure は弱い。  
再設計では「短期の上乗せゾーン」にする。

- 5G固定
- 毎G最低報酬あり
- レア役で上乗せ
- 最終Gで高確以上へ

### 12.2 王権ラッシュ

- `kingGauge` 解放
- 10G + 継続抽選
- 攻撃特化
- 防衛戦連鎖率アップ

### 12.3 星告モード

- `queenGauge` 解放
- 10G + 継続抽選
- 回復、神託一致、宝島優遇

### 12.4 世界制圧モード

- 最上位 AT
- `世界`、ボス撃破、ロングフリーズ契機
- 強アルカナ固定
- 敵襲高頻度
- 大量獲得区間

## 13. フリーズ設計

### 13.1 フリーズの役割

フリーズは「最高期待の契機」であることを明確にする。

### 13.2 契機

- `愚者`
- `世界`
- ボス勝利後抽選
- 強レア役連続

### 13.3 恩恵

- jackpot coin
- 国家ランク即上昇
- 上位AT突入
- 強アルカナ固定
- 特別演出

### 13.4 禁止事項

フリーズ後に弱い単発報酬で終わる設計は避ける。

## 14. 出玉設計

### 14.1 役の役割分担

- ワンペア
  - 出玉弱
  - 進行強
- ツーペア
  - 出玉小
  - CZ 期待
- スリーカード / ストレート
  - 中間
- フラッシュ / フルハウス
  - 強い契機
- フォーカード以上
  - ボーナス級

### 14.2 設計原則

- 通常時は小当たりの積み上げ
- ボーナスで中まとまり
- 上位状態で伸ばす

### 14.3 期待バランス

1スピンごとに次のどれかが起きるべき。

- 少量出玉
- ゲージ増加
- 状態昇格示唆
- CZ 接近
- 強演出示唆

何も起きないスピンを連続させすぎない。

## 16. 演出方針

### 16.1 重要演出

- レバーオン時の予兆
- ストップごとの違和感
- 第3停止後の溜め
- 神託一致
- 法則崩れ
- CZ 突入
- 敵襲カットイン
- 上位状態突入
- フリーズ

### 16.2 気持ちよさの条件

- 1スピンが長すぎない
- 当たり時の報酬が即分かる
- 上位状態突入は明確に区切る
- 通常時にも違和感演出を散らす

## 17. Phaser 導入方針

### 17.1 結論

Phaser は導入する価値が高い。  
ただし、面白さの土台を現行 engine で確定させた後に行う。

### 17.2 Phaser を使う範囲

- リール描画
- カード停止
- ライン発光
- 被弾演出
- 城壁アニメーション
- 敵襲演出
- フリーズ演出
- 画面揺れ
- パーティクル

### 17.3 Phaser を使わない範囲

- 役判定
- ゲージ進行
- 状態遷移
- 出玉計算
- 大アルカナ効果

これらは現行の engine 相当の pure logic に残す。

### 17.4 実装原則

- `spinTarotEngine.js` は renderer 非依存を維持
- Phaser は state を受けて描画する adapter にする
- DOM 版はデバッグ UI として残せる設計にする

## 18. 保存仕様

### 18.1 保存するもの

- 現在 state
- 各ゲージ
- 現在の大アルカナ
- 現在の状態
  - 通常 / 高確 / CZ / battle / AT
- 残りG
- run 開始時刻
- 直近の演出 seed

### 18.2 保存先

初期段階では local 保存でもよい。  
将来的には PlayFab 側保存を検討する。

### 18.3 保存タイミング

- 各スピン終了時
- 状態遷移時
- タブ離脱時

## 20. 成功指標

以下を満たせば、パチスロ寄り再設計は成功と見なす。

- 通常時でも10G以内に何かしら進行が見える
- 30G以内に1回以上、前兆またはCZ期待演出が起きる
- 1スピンごとの操作継続率が高い
- 「もう1回回したい」理由が毎回ある
- 防衛戦到達が遠すぎると感じにくい
- フリーズ、上位状態、AT が明確な目標になる

## 21. 非目標

本仕様では、以下は優先対象外とする。

- 対人要素の追加
- 課金仕様
- 本格的なスロット規制模倣
- 実機完全再現

目標はあくまで「パチスロ的な期待と快感を持つ、独自のタロットスロット体験」である。

## 22. 実装優先判断

最優先は以下。

1. 通常時の期待設計
2. 死にゲージの役割付与
3. 外れの進行価値
4. 状態の可視化
5. run 保存

Phaser はその後でよい。
