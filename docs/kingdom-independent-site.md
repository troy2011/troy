# タロットキングダムの通常対戦と独立サイト

2026-11-16。主担当はタロット・戦闘・探索ゲーム。統合境界は以下のとおり。

通常の新規オフライン対戦は `rules.tableRulesVersion: 1` と `openingRescueVersion: 1`。
同数字はワンド（火）↔カップ（水）、ソード（風）↔ペンタクル（大地）、大札入りは同数字へ返せる。
小札Aへ大札は返せない。同強度の5枚役には返せない。
15〜19・21の空場初手制限は最後の1枚のみ解除し、その上がりだけ+1翻。
役の星加算は2/2/3/4/5/5/10、コールは各-1。Worldは5、コール4。

`ROLE_RATE` は戦闘ダメージとAPの既存契約なので変更しない。TROY内のチップ・恒久報酬・Gの計算や保存先も変更しない。
冒険・ステージ・レイド・チュートリアルは既存ルール。保存済みの無指定フラグは0へ正規化し、途中の対戦を移行しない。

既存RTDBクライアントにはルールの能力交渉がなく、未知フラグが保持されない。TROY内の既存オンラインはv0に固定する。
NET_SCHEMA、RTDBパス、database.rules.json、PlayFab PlayerData／Statisticは変更しない。
新しいオンラインの正本は独立SiteのD1。TROY認証、LINE、PlayFab、Firebaseを持ち込まない。
旧卓上戦URLは独立Siteへの移転案内として保持し、専用コード・CSS・背景とその試験は独立リポジトリへ移す。
共用の海賊タロット画像はTROYでも引き続き使うため保持する。

独立Site: https://tarot-kingdom-online.bar-troy2011.chatgpt.site
公開範囲はSites側で管理。TROYユーザーのアカウント／レートは自動移行しない。
独立Siteのルーム・操作・レートはSites本人性とD1を正本とする。ブラウザからの勝敗・スコア申告は受け付けない。
ロールバックはTROYのこの変更前コミットへ戻す。新規フラグなしの保存は旧挙動のまま読める。
独立Siteは保存済みバージョンへ戻せる。D1の初回追加テーブルは削除せず、新旧コードで互換性を維持する。
