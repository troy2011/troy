> 以下は公開前の開発検証記録です。統合公開時の範囲と確認は [startup-kingdom-release.md](startup-kingdom-release.md) を参照。

公開済みタロット画像対応 2c385002b1c9d075d17c696ad691349e189f3992 を基準に、別のローカル開発チェックアウトで実装。push・deploy・本番変更はしていない。

## 適用範囲と実装

- public/js/tarotKingdom.js：新規の通常 online/offline 対戦に openingRescueVersion=1 を設定。欠落した旧保存データは0。探索セッション、探索stage、raid、tutorialでは無効。
- 親が初手不能なら既存の1枚ドローと親移動を使用し、通常新ルールでは3回ドローのKOを無効化。最後1枚の初手条件はドロー前に解除する。
- 世界21の通常1枚出し初手禁止は現行に既に存在。最後1枚だけを共通例外にし、通常の重ね出し、11バック制限、5枚役の条件は維持。
- 合法出札で手札0なら、攻撃・世界・その他の札効果より前に既存の勝利処理へ入る。既存の役成立時の星・アルカナポイント加算は共通化して保持。
- スキップ処理は変更なし。教皇Vの2人スキップを3人/4人で検証。小アルカナ5の枚数別処理も既存のまま。
- ルールブックには新規通常対戦だけに説明を表示。新しいテスト用の状態変更APIは本番コードへ追加していない。

## 既存の引き分け・山札切れ

resolveEmptyFieldLeader は以前から親を回し、全席が初手不能で山札が空、または全席が補充不能なら startKingdomDrawRetry で引き分け・再戦にする。補充可能なら同じ探索を続ける。今回はこの既存処理を維持した。256回の保護上限など、既定の引き分け条件と確認できない再戦はシミュレーションでは unresolved として区別する。

5,600局では引き分け・再戦は観測されなかったが、境界テストは別に実行した。3人全員が条件付き札だけを2枚ずつ持つ空山状態で、親が0→1→2と一周して既存の再戦へ移ること、強制ドローが0であることを確認。山札が空でも親に合法手があれば続行し、親だけ初手不能で次の席に合法手があればその席へ移ることも確認した。山札切れ単独で即終了する新ルールは追加していない。

手札上限8枚も変更していない。実ルールで78枚を全数判定した結果、通常の初手不可札は15・16・17・18・19・21の6枚だけだった。重複のない通常78枚では、全て初手不能の札だけで8枚になる状態は到達しない。重複札など別デッキを導入する場合の上限例外は今回決めていない。

## 比較方法

現行は git show 2c38500:public/js/tarotKingdom.js の実ファイル、変更案は開発版の実ファイルを Node VM で実行した。合法手列挙、出札、パス、親解決、配札・開始場、特殊効果、戦闘、移行、勝利判定は実関数であり、別の簡略ルールを再実装していない。DOM描画・画像プリロード・タイマー・外部通信をテスト用に置き換え、時間を進めて同じ移行処理を実行する。外部通信は実行不可、効果JSONはローカルから読む。

各人数100配札seed（1〜100）を、3人は全3席・4人は全4席へ回した。2方策×既存2設定×現行/変更案で計5,600局。ペアごとに手札・残山・開始場・開始席のSHA-256一致を確認。全席のキャラクター能力は同じ既存プレビューキャラクターに固定した。

hp-zero は現在の通常モードの既定値。通常モードもアプリ内部では敵HPと4局の清算を持つ。hand-empty は既存の終了条件設定を使った出し切り側の感度比較であり、現在のアプリ既定値や別の純粋PvPモードと同一視しない。

今回の救済・世界の初手制約・合法出札直後の手札0優先判定は、いずれの終了条件でも新規通常対戦に適用される。hp-zeroでは敵HPが先に0になって終わる場合がある。ユーザーの物理ルールの「出し切った人が勝つ」に対応する比較設定はhand-emptyだが、この設定でも既存の戦闘・味方全滅処理は残るため、HPのない物理対戦そのものの検証ではない。独自のHP無効モードは作っていない。

方策shedは合法手のうち手札を最も多く減らすもの、conserveは最も少なく減らすものを選ぶ。同数なら低い強さ、次にカードIDで固定。両方とも合法手があれば出し、任意ドロー・審判回収はスキップ、12トラッシュは先頭の合法候補を選ぶ。

1局の勝者または既定の敗北・再戦までを評価し、4局清算・報酬・実オンライン通信は評価していない。手番上限1,000、演出ループ上限8,000。打切りや未解決は終了に算入しない。今回それらと実行エラーは全て0件。試行回数には同一配札の席替えと方策違いが含まれ、独立な配札数は100である。

## 観測されたケース

3人・hand-empty・shed・seed10・席回転0では、現行の勝者は席2、変更案は世界を初期保持した席0が28手番で世界を出して手札0勝利。席回転1では現行は席1、変更案は世界保持席2が27手番で勝った。固定seedでこの過程を再現できる。

通常のhp-zeroでは手札0に届く前に敵HPの条件で終わることが多く、今回の比較で勝者と手番分布は変わらず、3人の強制ドローだけ15→7。出し切り設定では3人257→55、4人319→70に減った。世界の手札0勝利は3人0→34、4人0→12。ただし世界の勝ちやすさが上がるため、これを強さが下がった結果とは解釈しない。

4人hp-zeroの席1勝率32%など、開始順の偏りは残る。100配札の参考値であり、ルールの公平性や人間が遊んだときの面白さは保証しない。
