# 起動改善・Kingdom初手救済の統合公開

基準は公開済み `2c385002b1c9d075d17c696ad691349e189f3992`。起動改善6ファイルとKingdom開発6ファイルを、元のユーザー変更を含まない公開専用コピーへ統合した。

## 公開範囲

- 起動：inventory/uiの重複取得解消、同じ字体の非ブロッキング読込、原寸AVIFと元画像へのフォールバック。
- 新規通常対戦：初手不能時のドロー/親移動、最後1枚の初手条件解除、世界の通常初手制約、合法出札直後の手札0勝利優先。スキップ不変。
- 既存保存対戦はルールフラグ欠落時0を維持。探索・raid・tutorialは新ルール対象外。5,600局比較とゲーム本体SHAが一致する。
- 公開時のキャッシュ整合としてindexのmain/ui、mainの救難Kingdom読込、uiのKingdom読込、プレビューのui/Kingdomだけ `20261022-startup-kingdom-v1` へ更新した。既存対戦の状態やSWキャッシュ世代は変更しない。
- 新たな旧キャッシュ試験は古いmain/ui/Kingdomのコードをキャッシュへ置き、新版の入口がそれを使わないことと、新旧対戦の判定差を実ブラウザで確認する。

サーバー・認証・API・DBルール・ユーザーデータ・報酬・LINE・有料プラン・タロット採用画像/セルフ占いには変更なし。旧キャッシュを全消去したり、稼働中クライアントを強制再読込したりしない。

## 確認記録

開発時点の詳細は [起動改善](startup-bootstrap-dev.md) と [Kingdom比較](kingdom-opening-rescue-dev.md)。起動の実測はローカル同条件比較であり、本番で同じ短縮量を保証するものではない。

統合コピーで `node --experimental-vm-modules --test tests/kingdom-opening-rescue.test.cjs`、対象ブラウザ試験、既定npm全体試験、CSS lint、文字コード検査を行う。既存の基準版回帰失敗は期待値を変えず記録する。

公開経路は既存のGitHub mainへの限定fast-forward pushとRenderの自動デプロイ。本番の変更ファイル・保護対象の78枚/78サムネイル・セルフ占い等を静的SHAで照合し、新規の隔離ブラウザで非破壊確認する。実認証・実顧客情報・報酬消費・LINE送信は検証に使わない。

実際の公開commit、CI、配信照合、公開後ブラウザ結果は、このローカルタスクの `evidence/startup-kingdom-deployment/` に保存する。公開成功はpushだけでは判断せず、実配信との一致を確認する。
