# タロットキングダム 卓上戦

2026-11-14。`/tarot-kingdom-table.html`。モンスターや人物を使わず、78枚のタロットだけで3〜4人が卓を囲み、チップをやり取りする独立したカードゲーム。自分1人とコンピューター2〜3人で遊ぶ。

既存の `tarotKingdom.js`（探索・戦闘つき）とは別物で、コードも共有していない。認証・API・PlayFab・Firestore・localStorage は使わない。チップはこの画面の中だけの数字で、G・報酬・ランキングとは無関係。

## 構成

- `public/tarot-kingdom-table.html`、`public/css/tarot-kingdom-table.css`
- `public/js/kingdomTable/rules.js`：一局の札のルール（DOMなし）
- `public/js/kingdomTable/match.js`：チップと局の進行
- `public/js/kingdomTable/ai.js`：コンピューターの打ち方（自分の手札と場だけを見る）
- `public/js/kingdomTable/ui.js`：画面
- `public/js/kingdomTable/package.json`：このフォルダーを Node から ES module として読むための指定（テスト用）

## 札のルール

`public/tarot-kingdom-real.html`（2026-10-23版）のとおり。通常出し1〜3枚、調和、5枚役7段階、コール、5スキップ、8カット、11バック、12トラッシュ、ロイヤルロック、大札の専用条件、初手救済、手札0枚の勝利優先。

説明書に明記がなく、この実装で決めた点：

- 番が回る相手は「パスしていない次の席」。最後に出した人に番が戻った場合、その人は自分の札に重ねるかパスできる。最後に出した人以外の全員がパスした時点で場を流す。
- 小札と同じ数字の大札（例：小札5と大札5）は同じ数字として一緒に出せる。小札Aと大札1・大札15は別の数字。
- 5枚役では大札はその番号の数字として数える。愚者は数字のワイルドで、スートのフラッシュには入らない。
- 2枚以上の8、世界による即流しでは12トラッシュは起きない（全員のパスで流れたときだけ）。
- 最初にめくった場札が世界なら、その場で流して親から始める。

## チップと翻（この卓上戦のルール）

- 各自1000枚で開始。4人なら4局、3人なら3局。親は1局ごとに次の席へ。
- 毎局、全員が20枚を場に出す。上がった人が場を取る。引き分けの局は場を次へ持ち越す。
- 5枚役で場を流すと、その役を出した人の翻が増える：ストレート・フラッシュ2、フルハウス3、フォーカード4、ストレートフラッシュ5、それ以外（ザ・ワールド、ファイブカード）10。コールで作った役は1翻少ない。
- 負けた人の支払い＝残った手札の枚数 × 翻 × 10枚。翻は上がった人の翻に、自分が残した小札Aの枚数を足したもの。持っている分までしか払わない。

依頼の指定になく、この実装で補った点：

- 上がりそのものを1翻と数える（役で場を流していない人が上がっても支払いが0にならないようにするため）。
- 5枚役で上がった場合（出して手札0枚）も、その役の翻を数える。より強い役で返された役は翻にならない。
- 誰かのチップが0になるか、全局が終わると終了。チップの多い順に順位。

最初の版にあった「勝負」の宣言（50枚で+2翻）は、依頼者の判断で削除した。

2026-11-14 追加（依頼者の採用）：

- 親は上がれば+1翻、負ければ自分の支払いが+1翻。
- 親が上がると親を続け、同じ局をもう一度行う（連荘、「第1局 1本場」と表示）。親以外が上がるか引き分けなら、親は次の席へ移り局が進む。
- 連荘が続いても、試合は局数の2倍の回数で終わる。

数値は `match.js` の `CHIP_RULES` と `rules.js` の `ROLE_HAN` にまとめてある。

## 絵柄

札は海賊タロットの採用原画（`public/assets/pirate-tarot/thumbs/`、拡大時は `cards/`、裏面は `back.webp`）を、アプリ本体と同じ版・配信番号のURLで読む。スート色は細い外枠線で示す（ワンド赤、カップ青、ペンタクル緑、ソード黄、大アルカナ白）。数字とスート記号は絵の外の小さな共通色の見出しにまとめ、原画は切り抜かず全体を表示する。画像が読めないときも数字と記号は残る。札の正式名はアクセシブル名・ツールチップ・拡大表示に含める。場と結果の札は押すと原画を大きく表示する。表示名はペンタクル、ルール内のスートキーは既存の `coin` のまま。

対戦相手は卓の上段に配置し、場札には卓の横幅を使う。手札は大きめの札を少し重ねた扇形で、選択した札が上がる。手札の構成が変わらない選択操作ではボタンを再生成せず、キーボードのフォーカスを保つ。Tabで札や操作を移動し、SpaceまたはEnterで選択する。拡大表示はEscapeでも閉じられ、元の札へフォーカスが戻る。結果・回収・拡大の表示中はTab移動がその表示内に収まる。

### 酒場の画面（2026-11-14）

依頼者が選んだ画像案2「海賊船の酒場」を基準に、ランタンの船内・地図模様の木製卓・3人の海賊・チップの山を画像素材として用意した。初版の素材は `public/assets/tarot-kingdom-table/tavern-v1/` に保存し、背景以外は透過を維持したWebP。5枚の合計は約694KiB。チップ・手札枚数・翻・親・手番はゲーム状態から別のDOMへ表示する。3人卓では必要な2人のみを表示する。

場札は `perspective(650px) rotateX(27deg)` で卓に沿わせる。手札・操作ボタン・説明文は正面を保つ。画像にはUIの文字を焼き込まず、「1枚引く・パス・出す」、局数、残高と清算は既存ルールに従う。画像案にあるレイズ・ベット額の調整・制限時間は追加していない。

画面の配色と構成の確認点は、暖かいランタンと木目、独立した3人の人物、卓に寝かせた場札と手前の扇形の手札、金縁の残高・名前表示、紫・青・赤の操作ボタン。原画は既存の海賊タロットを使い、依頼者の指定どおり細いスート色の外枠と絵の外の数字を保つ。人物名と操作名、8枚の手札に合わせた密度は、このゲームの表示を優先する。

生成には組み込みの Image Gen を使用。再生成用の短いプロンプトは [prompts.json](../public/assets/tarot-kingdom-table/tavern-v1/prompts.json) を参照。表示変更の取り消しはHTML・CSS・`ui.js`の酒場に関する差分とこの素材フォルダーを対象とし、ルール・試合進行・保存場所の変更は伴わない。

### 対戦相手の手札との連動

人物に描かれた固定の札を外した透過画像を `tavern-v2/` に追加し、実際の残り枚数と同じ数の裏向きカードを手元に重ねる。描画に使う情報は `round.players[seat].hand.length` のみで、札の表・スート・IDは相手の手札表示へ渡さない。出札・ドロー・回収・新しい配札で枚数を更新し、0枚では扇を隠す。数字は大きく表示し、残り1枚は「あと1枚」と強調する。

手元の位置は人物画像の実際の表示寸法と握り位置から計算する。画像読込時と `ResizeObserver` により、画面サイズの変更や3人／4人の切替にも追従する。札の扇は既存のカード要素を使い回して開閉し、動きを抑える設定ではアニメーションを止める。変更は表示のみで、ゲームルール・所持品・永続データは変更しない。人物画像の編集プロンプトは [tavern-v2/prompts.json](../public/assets/tarot-kingdom-table/tavern-v2/prompts.json) に記録する。

### 演出と効果音（2026-11-14）

表示のみの追加で、ルール・チップの計算・試合進行は変更しない。`public/js/kingdomTable/effects.js`（画面の演出）と `sfx.js`（効果音）に分け、`ui.js` はゲームの出来事（`round.events`）から演出を順に再生する。演出はページ上の固定レイヤー（`.kt-fx`、操作を妨げない）に描くので、再描画で途中で切れない。動きは transform と opacity だけ。

- 配札：山札から手札へ1枚ずつ配られ、最初の場札が山から飛ぶ。
- 出札：自分の札は手札の位置から、相手の札は相手の手元から場へ弧を描いて飛び、着地で輪と火花。2枚以上・5枚役・世界は卓が揺れる。
- 5枚役・コール：卓を横切る帯で役名と「場を流せば+N翻」を表示。4翻以上は光、10翻はさらに放射光。
- 8カット・11バック・スキップ・ロック・除外・回収：場の下側にスタンプ（札は隠さない）。
- パス・親を渡す：その席の名札の上に吹き出し。
- 場流し：場の札が横へ流れて消える。
- 翻：流れた後の空いた場の中央に「+N翻」が出て、その席の翻表示へ飛び、表示が跳ねる。
- 上がり：「上がり！」のスタンプ、卓の揺れ。負けた席と場からコインが勝者へ飛び、各席のチップが実際の値まで数え上がってから結果を開く。結果の増減も数え上がる。
- 自分の番：手札の上を光が通る。試合に勝つと紙吹雪。
- 効果音：Web Audioでその場で合成（音声ファイルなし）。上部の♪ボタンで切替。設定はこの端末の localStorage（`troy:kingdom-table:sound`）に保存する表示上の好みだけ。
- 相手は演出が終わるのを待ってから次の手を打つ。
- 「相手の手番を速く進める」（`?fast=1`）では演出も音も出さない。動きを減らす設定では、飛ぶ・揺れる・光る・紙吹雪を止め、吹き出し・スタンプ・帯の文字だけを動かさずに出す。

同時に、山札の枚数を読める大きさの札入れに、題字を人物より手前の札板に変え、翻の表示が場札に重ならない位置に移した。
